Acre — Free Property Marketplace Website Template by uiCookies

CONCEPT
Acre is a proptech listings marketplace with a confident, editorial identity — deliberately
the opposite of the flat, light "success-green" agency template. The signature idea is a dark
navy hero with a search "command bar" that floats over the fold (segmented Buy / Rent / Sold
tabs), backed by a verified-listings grid whose favourite hearts actually work and persist in
the browser. Depth comes from a bento-style popular-cities mosaic, browse-by-type tiles, a
three-step "how it works" band, and a rated top-agents row. Built on Bootstrap 5 with vanilla
JavaScript and inline SVG icons only — no jQuery, no icon fonts, CSP-clean.

PALETTE
  Ink navy   #0C1E33  — structure, hero, dark sections, footer
  Slate      #15304A  — dark surfaces
  Azure      #2E6BF0  — primary interactive: links, active tab, focus, map pins
  Amber      #F5A524  — money, favourites, "just listed", accents (the confident spark)
  Porcelain  #F5F2EC  — warm hued-neutral light sections (not a cold grey)
  Slate-mute #5B6B7A  — secondary text
A warm-meets-cool two-accent system: azure carries trust/interaction, amber carries value.

FONT PAIRING
  Display: Bricolage Grotesque (600–800) — characterful contemporary grotesk for headlines
  Body:    Hanken Grotesk (400–700)      — clean, highly legible UI + copy
Deliberately avoids Inter and Space Grotesk.

NOTES
  - Favourite toggles and listing filters are live on the front end; favourites use localStorage.
  - The search bar and account/newsletter forms are front-end demos — wire them to your backend.
  - Reveal animations, count-ups and smooth scrolling all respect prefers-reduced-motion.
